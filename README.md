# 🎙️ AI Meeting Assistant (AI 회의 비서)

실시간 회의 음성을 기록하고, AI가 핵심 내용을 요약하여 일정 및 할 일을 자동으로 관리하는 지능형 웹 서비스입니다.

## 📝 프로젝트 개요
목표: 실시간 회의 음성을 기록하고, AI가 핵심 내용을 요약하여 일정 및 할 일을 달력에 자동 등록하는 지능형 웹 서비스 구축

## 1. 주요 기능 (Core Features)
- **STT (Speech-to-Text):** CLOVA Speech를 활용해 회의 음성을 실시간 텍스트로 변환.
- **AI 분석 및 요약:** HyperCLOVA X와 RAG(내부 문서 참조)를 결합하여 논의 안건과 결정 사항 추출.
- **일정 자동화 (Magic Step):** 사용자가 직접 입력하지 않아도 AI가 추출한 일정 데이터(JSON)를 구글/네이버 캘린더 API와 연동하여 자동 등록.
- **To-Do 리스트 관리:** 회의 중 나온 '해야 할 일'을 담당자별로 정리하여 대시보드에 표시.

## 2. 기술 스택 및 인프라 (NCP 기반)
- **Compute:** NCP Server (2vCPU, 4GB Mem) - 웹 서버 및 API 오케스트레이터.
- **AI SaaS:**
  - **CLOVA Speech:** 음성 인식 및 화자 분리.
  - **CLOVA Studio (HyperCLOVA X):** 텍스트 요약 및 구조화된 데이터(JSON) 생성.
- **Database:** Cloud DB for MySQL (회의록, 유저 정보, 일정 데이터 저장).
- **Storage:** Object Storage (음성 원본 파일 보관).
- **Network:** VPC 및 Subnet 설정을 통한 보안망 구축.

## 🔄 데이터 흐름 (Workflow)
1. **입력:** 웹 사이트에서 회의 시작 버튼 클릭 (음성 데이터 스트리밍).
2. **변환:** CLOVA Speech가 음성을 텍스트로 변환하여 서버로 전송.
3. **지능형 처리:** 
   - 변환된 텍스트를 HyperCLOVA X가 분석.
   - RAG를 통해 관련 사내 문서나 이전 회의록 정보를 참고하여 맥락 파악.
4. **결과 생성:** AI가 요약본과 함께 `{일정: "5월 20일", 내용: "디자인 리뷰"}` 식의 데이터를 추출.
5. **자동 실행:** 서버가 달력 API를 호출해 일정을 등록하고, DB에 최종 회의록 저장.

## 🚀 기대 효과
- **효율성:** 회의 후 수동으로 정리하던 시간을 획기적으로 단축.
- **정확성:** AI가 일정을 직접 추출하므로 날짜 오기입 등 인적 오류 방지.
- **최적화:** NCP SaaS를 적극 활용하여 낮은 서버 사양에서도 고성능 서비스 구현 가능.
